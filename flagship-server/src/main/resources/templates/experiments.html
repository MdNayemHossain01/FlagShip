Statistical Assumptions & Limitations
Core Assumptions
  • Independent Observations: Each user exposure and subsequent conversion is assumed independent. Network effects or cross-device identity changes may bias results.
  • Large Sample Normal Approximation: The two-proportion Z-test relies on the Central Limit Theorem. Requires $n \cdot p \ge 5$ and $n(1 - p) \ge 5$ in each group.
  • Binomial Conversions: Each exposed user has a binary outcome (converted vs not converted).
Limitations & Pitfalls
  • Peeking Problem: Continuously inspecting p-values before reaching planned sample size inflates False Positive Rate. Use fixed sample sizes.
  • Sample Ratio Mismatch: If SRM occurs (p < 0.001), traffic assignment is broken (e.g. redirection latency or bot filtering). Do not make release decisions when SRM is present.
